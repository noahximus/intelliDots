# superfile

Standalone Superfile (terminal file manager) installation and theme
configuration. Part of `toolsDots/devTools` in `intelliDots`.

## Install

From the `intelliDots` root:

```bash
./install.sh --only toolsDots.devTools.superfile
```

Or directly:

```bash
cd toolsDots/devTools/superfile
./install.sh
```

```bash
./install.sh --dry-run
./install.sh --no-brew
./install.sh --adopt
```

## Uninstall

```bash
./uninstall.sh
./uninstall.sh --brew    # also uninstall the superfile formula
./uninstall.sh --dry-run
```
